从安装到翻译，只需四步。

当前版本通过 Chrome 的本地扩展方式加载，不需要额外账号。

  1. 01

    打开扩展程序页面

    在 Chrome 地址栏输入 chrome://extensions，然后回车。

  2. 02

    开启开发者模式

    打开页面右上角的“开发者模式”开关。

  3. 03

    加载插件文件夹

    点击“加载已解压的扩展程序”，选择插件所在文件夹。

  4. 04

    填写 API 配置

    点击工具栏图标，填入 Base URL、API Key 和模型名称，保存后即可使用。可先点击“测试连接”确认接口可用。
